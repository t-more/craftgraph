# CraftGraph 0.1

The first version put out for testing, for World of Warcraft Forever.

## What it does
- A graph of what any item is made from and used in, with buy, make and sell buttons.
- Opportunities: every way to make money now (craft, relist, vendor routes, bag sales), with what
  it costs, what it should earn and how sure that is.
- Plans: a small window with the next step, the profit a plan should earn now, how the last scan
  moved it, and its median and average since it was planned.
- When to sell: the price by hour of the week, and the best hour to sell what you hold.
- How fast things sell, judged from auctions that vanish between full scans.
- Auto scan while the auction house is open.
- Forecasts are held back, with the reason, when there is too little to go on.

## Know before you try it
- Most of this version has only been checked outside the game.
- The Windows installer has not been run on a Windows machine.
- The optional Python tool (online prices, scan database) is experimental.
